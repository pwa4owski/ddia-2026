# Сервис бронирования переговорок

REST-приложение на Java 25, Spring Boot 4.1.1, Spring JDBC и H2 в памяти.
Запуск выполняется вместе со стендом через Docker Compose — [инструкция](README.md).
Базовый адрес: `http://localhost:8080`.

## Модель данных

Бронь содержит `id`, `room`, `date` и `hour`. Идентификатор назначается сервером.
Комната, дата и час образуют уникальный слот; повторно занять его нельзя.

| Поле запроса | Формат |
| --- | --- |
| `room` | Непустая строка до 100 символов; регистр и пробелы значимы |
| `date` | Дата `YYYY-MM-DD`; прошедшие даты разрешены |
| `hour` | Целое число от 0 до 23 |

Все три поля обязательны. Бронь действует один час: `hour: 14` означает
интервал `[14:00, 15:00)`. Время трактуется в `Europe/Moscow`;
преобразование часовых поясов не выполняется.

## HTTP API

| Метод | Путь | Действие | Успешный ответ |
| --- | --- | --- | --- |
| POST | `/bookings` | Создать бронь | 201, бронь в теле и заголовок `Location` |
| GET | `/bookings/{id}` | Получить бронь | 200, бронь в теле |
| PUT | `/bookings/{id}` | Заменить комнату, дату и час | 200, обновлённая бронь |

POST и PUT принимают `Content-Type: application/json` и одинаковое тело:

```json
{
  "room": "A",
  "date": "2026-10-24",
  "hour": 14
}
```

В ответе возвращаются эти поля и `id`. PUT сохраняет идентификатор брони;
после успешного переноса исходный слот освобождается.

| Код ошибки | Причина |
| --- | --- |
| 400 | Некорректный JSON или значения полей |
| 404 | Бронь с указанным ID не найдена |
| 409 | Комната уже занята в выбранный слот |

Ошибки возвращаются в формате Spring Problem Detail.
При конфликте обновления исходная бронь сохраняется.

Готовые запросы находятся в [requests/bookings.http](requests/bookings.http)
для HTTP Client в IntelliJ IDEA. Они выполняются сверху вниз: создание
сохраняет ID и случайное имя комнаты для последующих GET и PUT.

## Устройство

`BookingController` принимает HTTP-запросы, `BookingService` выполняет операции
с бронированиями, `BookingRepository` обращается к H2 через `JdbcTemplate`.
Уникальность слота обеспечивается ограничением базы данных.
Хранилище находится в памяти процесса; при остановке приложения брони теряются.

Библиотека `http-metrics-spring-boot-starter` подключена как Gradle-зависимость
и автоматически инструментирует методы контроллеров.

| Техническая ручка | Назначение |
| --- | --- |
| `/actuator/health` | Проверка готовности приложения |
| `/actuator/mappings` | Список маршрутов для CLI-генератора |
| `/actuator/prometheus` | Экспорт метрик для VictoriaMetrics |

Технические ручки исключены из прикладной метрики `bookings.request`.
Её серии `bookings_request_seconds_bucket`, `_count` и `_sum` имеют labels
`deployment`, `datacenter`, `pod`, `method`, `route` и `status`.
В `route` записывается шаблон `/bookings/{id}`, общий для всех ID.
